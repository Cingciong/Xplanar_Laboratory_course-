# Topic 3 start, hardware

`Normal` mode, real stand, 12 tiles, 4 movers.

## What it does

Starting point of topic 3: configured system, no PLC program yet. The student adds the PLC project.

## Run

1. Open `T03_start_HW.sln`, platform `TwinCAT RT (x64)`, target = the XPlanar controller.
2. Make sure the table is clear.
3. *Activate Configuration* and switch to Run Mode.
4. Check in *TwinCAT > MC3 > XPlanar Environment View* that all movers are detected.
