# Topic 2 solution, hardware

`Normal` mode, real stand, 12 tiles, 4 movers.

1. Open `T02_HW.sln`, platform `TwinCAT RT (x64)`, target = the XPlanar controller.
2. Make sure the table is clear.
3. *Activate Configuration* and switch to Run Mode.
4. Enable the movers and use JOG (*TwinCAT > MC3 > XPlanar Environment View*).

Status: generated from the simulation project and the stand settings of the demo. Builds, not yet tested on the stand.
