# Wstęp — zadania

Rozdział 1 instrukcji (1.6 Zadania). Zadania wykonuje się na projekcie demo `StarterkitBase` z folderu `demo/` (otwierać `demo/StarterkitBase.sln`).

- **Zadanie 1 (tryb Normal):** uruchomienie projektu na PLC lub na własnym komputerze w trybie `Normal`, ruch moverów z wizualizacji.
- **Zadanie 2 (BasicSimulation):** uruchomienie symulacji na PLC lub na własnym komputerze, ruch moverów z wizualizacji.
