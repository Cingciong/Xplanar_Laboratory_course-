# Topic 1 - demo, hardware

`Normal` mode, real stand, 12 tiles, 4 movers.

## What it does

Beckhoff Starter Kit demo: 4 movers run on 3 tracks between process stations. It is controlled from the visualization.

## Run

1. Open `T01_demo_HW.sln`, platform `TwinCAT RT (x64)`, target = the XPlanar controller.
2. Make sure the table is clear.
3. *Activate Configuration* and switch to Run Mode.
4. Log in to the PLC and press *Start*.
5. Open the visualization and start the movers.
