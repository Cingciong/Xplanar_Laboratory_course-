# Demo, hardware

`Normal` mode, real stand, 12 tiles, 4 movers. Stand AMS Net ID `5.148.231.151.1.1`.

1. Open `T01_demo_HW.sln`, platform `TwinCAT RT (x64)`, target = the XPlanar controller.
2. Make sure the table is clear.
3. *Activate Configuration* and switch to Run Mode.
4. Log in to the PLC, start it and move the movers from the visualization.
